# Retouch and Cutout (Cards 2, 3, and 6)

## Card 2 — Background removal and cutout

**Use when:** the user needs a transparent image, replacement background, ordinary editable mask, or precision clipping path. Typical cases include ecommerce products, portraits, furniture, food, transparent packaging, and compositing assets.

**Primary channel:** F1 for a standalone transparent/replaced-background result; W1 for a proved ordinary editable mask workflow in Photoshop Web; D1 for Pen/clipping path, a named unsupported web control, installed plugin, explicit Desktop lesson, or failed web fidelity.

**Escalation trigger:** move to W1/D1 only for the required editable object, explicit client, or a representative sample that fails the accepted edge oracle.

**Hybrid handoff:** F1 creates an approved first pass; deterministic tooling scores alpha/geometry; W1/D1 receives only retained-state or failed-edge cases.

**Verification:** compare known alpha or human-reviewed edge classes, halos, spill, holes, reflections, dimensions, and retained mask/path editability when promised.

Do not route to Desktop merely because the edge looks difficult. Run the required state through a known-alpha or human-reviewed representative sample and escalate on measured failure or a named retained object.

**Workflow:** classify required state, sample easy and hard edges, approve output, process by route, then inspect edge halos, semi-transparency, holes, reflections, alpha, and retained editability.

**Failure and recovery:** keep the source and first-pass mask; quarantine edge failures rather than hiding them on a convenient background.

**Record as skill:** one client-specific refinement lesson at a time, only after live replay.

**CU display:** conditional. Clipping-path or Desktop teaching is a valid CU story; a standalone transparent PNG is not.

## Card 3 — Conservative portrait retouch

**Use when:** portraits must match an approved reference while preserving identity and natural texture. Typical cases include event galleries, corporate headshots, school portraits, creator content, and licensed editorial sets.

**Inputs:** approved reference, allowed changes, protected regions, strength, output state, print/web requirements, and sample subjects across lighting and skin tones.

**Primary channel:** F1 for a conservative standalone result; W1 for ordinary retained layers/masks/healing that pass web round trip; D1 only for a named desktop-only tool, plugin, exact print behavior, or explicit Desktop lesson.

**Escalation trigger:** use W1/D1 only when retained editability, a named client/tool/resource, or a failed approved sample requires it.

**Hybrid handoff:** F1 establishes the approved look; W1/D1 preserves only the required reversible state or handles precision outliers.

**Verification:** compare protected identity regions, texture, reference match, approved strength, source preservation, and retained objects after reopen when promised.

**Workflow:** define protected regions, make one or two samples, obtain taste approval, process in small batches, and separate outliers. Compare identity, skin texture, edges, color, and reference match.

**Failure and recovery:** stop scaling when the reference is ambiguous or identity/texture changes exceed approval. Return untouched sources and an itemized review list.

**Record as skill:** record a proved deterministic setup or lesson, not subjective brush decisions as though they generalize.

**CU display:** conditional. Retained Desktop state or a lesson qualifies; ordinary flattened retouching should use the more direct route.

## Card 6 — Authorized cleanup

**Use when:** the user needs licensed clutter, bystanders, dust, or an owned overlay removed while preserving protected structure.

**Rights boundary:** remove a watermark or overlay only when the user owns the material or is authorized to modify it. Refuse ownership-evasion or provenance deception.

**Primary channel:** F1 for a standalone semantic repair; W1 for a proved web-retained healing/clone/mask workflow; D1 for a named desktop-only repair state, Action, plugin, or explicit lesson.

**Escalation trigger:** use a retained Photoshop route for a named app object/tool, approved reusable automation, or an observed native/web failure in protected or repeated structure.

**Hybrid handoff:** F1 handles approved standalone repairs; deterministic masks compare protected/removal regions; W1/D1 handles only required retained state or quarantined outliers.

**Workflow:** mark protected regions, sample simple and difficult cases, compare source/result, process in small groups, and quarantine repeated-pattern distortion or uncertain fills.

**Verification:** inspect protected regions, repeated textures, shadows, reflections, and continuity at high zoom; verify editable repair state only when promised.

**Failure and recovery:** never force a distorted fill. Preserve the source and route the item to review or a more controllable retained-state workflow.

**Record as skill:** only a closed app lesson or reusable Action branch.

**CU display:** conditional; advertise CU only for named Photoshop Desktop state, not generic object removal.
