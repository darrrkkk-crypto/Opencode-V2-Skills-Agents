<Tip>
**Auth:**

- **API Key:** Full access.
- **Standard OAuth client:** Requires `create_task` or `manage_all_tasks`. With `create_task`, only tasks created by the same client; see [Task visibility](https://open.manus.ai/docs/v2/open-app#task-visibility).
- **Trusted client:** Full access.
</Tip>

<Warning>
This action is permanent. If the task is still running, use [task.stop](https://open.manus.ai/docs/v2/task.stop) to stop it first. Agent-related tasks (e.g. agent main tasks and subtasks) cannot be deleted.
</Warning>
