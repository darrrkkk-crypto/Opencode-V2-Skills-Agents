<Tip>
**Auth:**

- **API Key:** Full access.
- **Standard OAuth client:** Requires `create_task` or `manage_all_tasks`. With `create_task`, only artifacts from tasks created by the same client; see [Task visibility](https://open.manus.ai/docs/v2/open-app#task-visibility).
- **Trusted client:** Full access.

**Guide:** Filter rules, artifact categories, URL lifetimes, pagination, and error codes are in the [Artifacts](https://open.manus.ai/docs/v2/artifacts) guide.
</Tip>
